猫仙音乐 2.0.0 —— 完整视觉 Remake

这是猫仙音乐的一次完整视觉重制：播放详情不再是「普通播放页 + 装饰背景」，
而是直接复用 Folia 的沉浸式歌词舞台。

## 视觉层（Folia 原码）

- 将 Folia 主分支的视觉系统整体 vendor 到 `src/renderer/folia-src/`，
  通过 React island 挂载在 Vue 页面中，业务层（播放器、音源、歌词、IPC、
  持久化）完全不变
- **14 种歌词视觉模式**全部接入：经典 / 华彩 / 阿卡贝拉 / 克拉达 / 立体景 /
  烟雾 / 光晕 / 莫奈 / 帕蒂塔 / 摆钟 / 十四行诗 / 静物 / 蛋彩 / 倾斜
- **6 种背景模式**全部接入：星野 / 潜影 / 莫奈 / 游牧 / 通用 / 自定义
- 封面取色主题通过桥接层进入 Folia 的 Theme 结构，参与歌词、背景与强调色渲染
- 歌词时间轴由真实播放时间（MotionValue）驱动；猫仙歌词只有行级时间戳，
  按行同步，不伪造逐字
- 模式切换带 Folia 的 softFocus 转场

## 设置

- 设置 → 播放详情 新增「Folia 歌词视觉」：歌词视觉模式与背景模式选择
- 视觉风格三档（关闭 / 轻量 / 完整）保留，完整档位启用 Folia 舞台

## 构建

- 新增 esbuild-loader 处理 Folia 的 React/TSX（只转译不类型检查）
- tsconfig 排除 folia-src，ts-loader 改为 transpileOnly
- webpack 别名 `@/` 指向 folia-src，Tailwind 扫描范围加入 tsx
- 三端构建通过：main / renderer / renderer-lyric

## 许可证

- 项目切换为 **AGPL-3.0**（视觉层直接复用 Folia 的 AGPL 代码）
- 新增 NOTICE 说明来源、修改与许可处理

## 已知限制

- 主界面其余页面（音乐库、搜索、歌单广场等）仍为此前的 Folia 风格实现，
  未在本轮替换为 Folia 原码组件
- 歌词逐字同步依赖数据：当前音源多为行级歌词，逐字效果仅在提供逐字
  时间戳的音源上生效
- 本发行说明中的构建结果为实际执行记录；运行截图受环境限制未包含
