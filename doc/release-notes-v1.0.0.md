猫仙音乐 1.0.0 —— 第一次以「猫仙音乐」的名字发布。

这不是 LX Music 的换皮版：界面、组件、主题与视觉引擎全部重写，只保留了音乐源兼容与播放内核。

## 新界面
- Folia 风格外壳：玻璃侧栏、悬浮播放胶囊、深色弹窗与统一的设计令牌
- 封面取色主题：强调色跟着当前封面走，亮暗随系统切换
- 设置窗双栏布局，15 个面板全部重做

## 播放详情
- 全屏音乐磁贴：当前播放队列的封面铺成缓慢流动的墙
- 3D 歌词走廊：逐词立在纵深里，随节拍点亮，镜头跟随当前行
- 星野背景：可切换为跟随封面取色的星空
- 视觉风格三档：关闭 / 轻量 / 完整，低配设备自动降级

## 桌面歌词
- 独立窗口接入同一套主题令牌
- 深色胶囊控制条，支持锁定穿透

## 品牌与数据
- 程序名、安装目录、快捷方式、协议（`maomusic://`）全部改为猫仙音乐
- 检查更新改为本仓库的 GitHub Releases
- 首次启动自动迁移 `%APPDATA%\lx-music-desktop` 下的歌单与设置

## 兼容
- 兼容 LX Music 音乐源与自定义源脚本
- 旧歌单、设置、下载记录可继续使用

## 已知问题

- 少数旧弹窗仍在逐步迁移到新样式
