# 猫仙音乐 v2.0.3

## 修复：升级后看不到 Folia 舞台

v2.0.0 起播放详情的沉浸式歌词舞台改为 Folia 原码（14 种歌词模式 + 6 种背景模式），但它只在「视觉风格 = 完整」档位挂载。
旧版本默认是「精简」（纯 CSS 渐变），已升级用户的配置文件里仍存着 `lite` 这个值，所以装上 2.0.x 仍然和以前没差别——这是之前「看起来一点没变」的真正原因。

本版在首次启动时把旧 `lite` 一次性升级为 `full`，无需手动改设置即可看到 Folia 舞台。

## 如何确认已生效

打开播放详情（双击Mini播放器或点右下角封面展开全屏播放页）：

- 背景出现 Folia 星野/潜影等动态背景
- 歌词以 3D 走廊等模式呈现，可侧边控制面板切换 14 种歌词模式 / 6 种背景模式
- 设置 → 播放详情 → 视觉风格 可手动在 完整 / 精简 / 关闭 间切换；若手动改回 精简，不会被自动升级覆盖

## 已知未完成（如实说明）

- 主界面、音乐库、搜索、歌单广场、排行榜、下载管理等页面仍为重构前的 Vue 实现，尚未替换为 Folia 原码组件
- 运行截图因环境无 GUI 未附
