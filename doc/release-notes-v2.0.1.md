猫仙音乐 2.0.1 —— 调优、逐字歌词与性能

## 新增

- **视觉模式调优面板**：设置 → 播放详情 → 当前模式调优，可为每种歌词视觉模式调整参数
  （如经典的逐词旋转/浮动幅度/词间距、立体景的相机速度/粒子密度/辉光、烟雾的相机速度/辉光等），
  实时生效并持久化
- **逐字歌词支持**：解析 LX Music 逐字歌词（lxlrc），有逐字时间戳时按词同步高亮；
  只有行级歌词时回退整行同步，不伪造逐字

## 优化

- **渲染性能**：播放时间与频谱强度改为通过 MotionValue 直接更新，不再每帧重渲染 React 树；
  歌词行、主题、模式变化才触发重渲染
- 组件卸载时取消 rAF 循环并 unmount React root，避免残留渲染循环

## 其他

- 版本 2.0.1，更新检查仍指向本仓库 Releases
