### 踩坑：Options API 组件必须注册
`<script>`（无 setup）里的 import **不会**自动暴露给模板，lucide 图标和 Ui* 组件都要写进 `components: {}`，否则 eslint 报 `no-unused-vars`、运行时白屏。已踩：`Upload`、`Volume2`、`Plus`/`RefreshCw`。
另外删除 `<style module>` 后，模板里残留的 `$style.xxx` 引用会抛 `Cannot read properties of undefined`，且 webpack 只在运行时报错。删样式块时必须 grep 一遍 `$style`。

### 大块模板替换的稳妥做法
`Edit` 工具匹配整段旧模板容易因空格/注释差异失败。改用 Python 按**行号区间**替换（`lines[:head] + frag + lines[tail:]`），再单独插 import / components。但插 components 时容易错位，务必 `grep` 检查 `export default {` 前的孤儿块。
